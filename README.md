# 乡村短剧 AI 创作助手

合肥工业大学新媒体中心赴黄山“乡村短剧赋能乡村振兴”调研暑期社会实践团队网页前端。

## 已完成

- 官方、活力兼具的响应式首屏主视觉
- 小狐狸、融媒体徽章和黄山三下乡元素整合
- 6 张实践图片自动轮播，支持手动切换与暂停
- AI 问答输入框、快捷提示词与多图片上传预览
- 生成时自动收起轮播区，为回答腾出空间
- AI API 接口位置已经预留，但没有写入任何密钥
- 可直接作为静态网站导入 GitHub，并由 Vercel 部署

## 本地预览

直接双击 `index.html` 即可；也可以在本目录运行静态服务器：

```bash
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 导入 GitHub

将压缩包解压后，把文件夹内的全部文件上传到仓库根目录即可。必须保留 `assets` 文件夹及其层级。

## 后续接入 API

在 `config.js` 中填写后端接口地址：

```js
window.APP_CONFIG = {
  apiEndpoint: "/api/generate"
};
```

前端会以 `multipart/form-data` 发送：

- `prompt`：用户输入的文字
- `images`：用户选择的图片，可为多张

接口返回 JSON 时推荐使用：

```json
{ "result": "模型生成的回答" }
```

请勿把 API Key 写入 `config.js`、`script.js` 或其他前端文件。密钥应保存在后端或 Vercel 环境变量中。

后端会根据用户问题匹配最相关的经验片段，再与系统角色提示一起发送给 DeepSeek。

## 中国大陆访问优化

当前项目在不购买自定义域名、继续使用 Vercel 默认域名的前提下，已做以下优化：

- Vercel Function Region 固定为香港 `hkg1`，减少调用 DeepSeek 时的跨洲往返。
- 前端不依赖 Google Fonts、国外 CDN 或第三方脚本；页面资源均由项目自身托管。
- 首屏背景改用更轻量的本地图片并预加载；下方内容启用延迟渲染。
- 图片上传到 AI 前会在浏览器内压缩至最长边约 1200px、单张目标约 780KB。
- 稳定文件名资源不再使用“一年 immutable”浏览器缓存，避免更新后用户长期看到旧版本。
- HTML、CSS、JS 使用较短浏览器缓存，静态图片使用 CDN 缓存，以兼顾国内重复访问速度和后续更新。
- API 请求超时与 Vercel Function 时长对齐，避免平台先行中断导致无提示失败。

注意：这些优化能改善“能访问时的速度和稳定性”，但无法保证 `.vercel.app` 在中国大陆所有网络环境下始终可达。如果后续需要更高的大陆可用性，仍建议使用备案域名与面向中国大陆的托管/CDN。
